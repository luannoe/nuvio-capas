# Capas e configuracao para o Nuvio

- `capas/`: capas deitadas (1280x720) de servicos de streaming do Brasil, usadas nas Colecoes do Nuvio.
- `home/aiometadata.json`: catalogos para importar no AIOMetadata (Catalogs > Import Setup > From URL, modo Merge).
- `home/colecoes.json`: colecoes para importar no Nuvio (Gerenciar pelo celular > Colecoes > Importar > URL).
